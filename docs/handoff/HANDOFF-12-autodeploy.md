**Доменный ресурс в Search Console.** Брат добавил TXT-запись, проверено `dig +short TXT vesnins.com` — запись на месте, старые (`mailru-domain`, SPF) не тронуты. Ресурс `sc-domain:vesnins.com` создан и подтверждён. Три префиксных ресурса оставлены как архив — история из них не переносится.

**Разобран хвост старого блога.** Google показывает по домену 1 285 страниц «просканирована, но не проиндексирована» + 37 canonical-вариантов + 34 копии, данные от 15.05.2026. Это остатки прежнего большого блога на этом домене. Блог утерян, сайта нет. Проверено, что сервер отдаёт честный `404` на любой несуществующий путь. **Решение: ничего не редиректим, старьё умрёт само за 3–6 месяцев.** К вопросу не возвращаемся.

Отдельно: `/?p=123` отдаёт `200` — это главная с игнорируемым «хвостом» в адресе, нормальное поведение статики. `canonical` на главной стоит правильный, поэтому дубли Google схлопнет сам.

**robots.txt и sitemap.xml на обоих поддоменах.** Индексация открыта полностью, возражений от Сергея нет. Полей `priority` и `changefreq` намеренно нет — Google их игнорирует. Из `donate/index.html` вычищена закомментированная заготовка счётчика с `ВАШ-ID` (живой Umami на строке 219 не тронут).

**Карты сайта отправлены** в Search Console и Яндекс.Вебмастер: для поддоменов `sitemap.xml`, для основного сайта `sitemap-index.xml` (у Astro имя такое; `sitemap-0.xml` — вложенный, отдельно не отправляется). В карте основного сайта 13 адресов, обе языковые ветки на месте.

**Починен автодеплой на поддоменах — главное за день.** Симптом: пуш проходит, сайт остаётся старым. Причина: у reklama и donate источником был `Public GitHub` — анонимное скачивание по адресу, при котором Coolify не имеет прав в аккаунте, не создаёт вебхук, и переключателя Automatic Deployment для такого источника просто не существует. Оба приложения переключены на GitHub App `reconcept-deploy` (тот же, что у основного сайта; доступ = All repositories). Проверено пустыми коммитами: сборка поднимается сама.

## 3. Грабли, которые стоили времени

- **Пустой вывод `git push` ≠ деплой.** Всегда сверять хеш коммита с тегом образа контейнера.
- **Выгрузка примеров URL из свежесозданного доменного ресурса приходит пустой** — там только заголовок CSV. Список наполняется при новых обходах, ждать недели.
- **`zsh` ломает цикл, если в списке есть адрес с `?`** — брать каждый элемент в одинарные кавычки.
- **Automatic Deployment живёт на вкладке Git Source**, а не General. Вкладка Webhooks — это адреса для ручной привязки, не индикатор.
- Кеш ни при чём, если ресурс отдаёт 404: кешировать несуществующий файл нечего. Диагноз — по хешу образа, а не по догадкам.
