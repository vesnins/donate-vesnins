# donate.vesnins.com

Страница поддержки канала «Мистер Полумарафон». Один файл `index.html`:
разметка, стили и скрипт внутри. Сборки и зависимостей нет — файл открывается
локально двойным кликом и выглядит так же, как на бою.

## Что где править

| Что меняем | Где искать |
|---|---|
| Ссылки на площадки | `<section id="ways">`, атрибут `href` у `.way` |
| Подписи «карты РФ / иностранные» | `.way__d` |
| Метка справа: разово или подписка | `.way__tag` |
| Порядок способов | переставить блоки `<a class="way">` |
| Какой способ выделен оранжевым | класс `way--main`, он должен быть ровно один |
| Список трат | `<ul class="spend">` |

## Счётчик

В `<head>` лежит закомментированное место под скрипт Umami. Пока строка не
вставлена, атрибуты `data-umami-event` на ссылках просто не срабатывают —
на вёрстку и переходы это не влияет.

Названия событий: `way-boosty`, `way-youtube`, `way-patreon`, `way-tribute`
для способов оплаты и `out-*` для остальных исходящих ссылок.

## Деплой

Тот же путь, что и у `reklama.vesnins.com`: `git push` в `main`, затем кнопка
**Deploy** в Coolify. Ресурс отдельный, Build Pack `Static`, образ
`nginx:alpine`, домен `https://donate.vesnins.com`.

После деплоя открывать страницу жёсткой перезагрузкой `Cmd+Shift+R` —
имена картинок не версионируются.

## Картинки

`img/og.jpg` взята из репозитория медиакита и используется только как превью
при отправке ссылки. На самой странице картинок нет.
